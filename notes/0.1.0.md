- **One queue for heavy test runs.** Test runs from every session on this computer wait in one queue and start when there is room, so suites no longer starve each other and fail for reasons that have nothing to do with the change.
- **Pushes go first.** A run a pre-push hook is waiting on starts before background checks; you can move any waiting run up, down or to the top, or cancel it.
- **See what is waiting, running and done.** Each run says which session and epic it came from, how long it waited and ran, and a failed run opens its output.
- **Results reach whoever asked.** An agent waits on its own run's result instead of watching the machine's load, and a failure is in your Inbox as needing you.
- **Your hook keeps working without it.** When Test runs is not running, the hook runs the checks right away and says so.
