- **Everything at a glance.** The top of Test runs is three small tiles with live charts: how many runs are running and waiting, how hard the computer is working against the limit where new runs wait, and how the latest runs came out.
- **More as it grows.** A small Test runs container shows only the tiles. Give it room and it lists each run on one line, then each run with its buttons, then where each came from and how long it took. It follows the container's size, not the window's.
- **No more "needs your attention" for test results.** Passing or failing, a run is quiet news in the Inbox, and its result stays on the page. The outlined border, "Needs your attention" and Mark as seen are gone.
- **Cancel from the run's details.** Opening a waiting or running run shows a Cancel button beside it, so even a small container can stop one.
