- **Go to where a run came from.** Each run has a jump-into button. It takes you to the epic, the kehikko and the parts the run was asked for from, when that is in the project you have open. When it cannot, the button is greyed out and its tooltip says why, for example that the run started outside any Kehikot project.
- **Output opens in a drawer.** Press Output on a run and a drawer opens for that run: its state, times and origin, and its output to read, copy or open in full. It comes from the side, or from the bottom on a narrow window, and Esc closes it.
- **Fixed: hiding one run's output opened another's.** Hiding the output of a failed run no longer opens the output of another failed run.
- **Test runs has its own icon** in Kehikot's list.
