- **Runs change on the page as they happen.** A run being asked for, starting, finishing or being cancelled shows up straight away, instead of on the next check up to fifteen seconds later.
- **Output arrives as it is printed.** A running test's output in the drawer grows as the test prints it.
- **Waiting and running runs say since when.** A run still waiting or running shows the time it was asked for or started, rather than a count of seconds that only moved when the page checked again.
- **Quiet while nothing moves.** An open Test runs page no longer asks every couple of seconds. It asks nothing at all while hidden or while nothing changes.
