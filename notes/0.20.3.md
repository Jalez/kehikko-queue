Kind: feature

- **Press a chart to change what it is about.** Pressing the Load chart opens Queue's settings at the load limit; pressing Waiting opens Runs at once. Each chart says so when you point at it. In a Kehikot too old to open them, the page says where they are.
- **One number for the load limit.** The setting is now the load itself — "Pause new runs above load", the same number and dashed line the Load chart shows, the footer's meter and the queue's reasons — instead of a load per core. A limit you set before is converted for this computer's cores.
- **Settings answer at once.** Queue answers its settings from memory, and asking where a run came from no longer holds Queue up while git answers.
