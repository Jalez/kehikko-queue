- **Agents use the queue on their own.** On a kehikko Queue is on, an agent session's typechecks, test suites, browser tests, builds and installs, and its subagents', go through the queue without being asked, and its dev servers into a leased slot. A test run of one file still runs at once.
- **Decided per project.** Whether a script is heavy is read from the project's own package.json, so a light script named build or test runs at once.
- **Yours to adjust.** In Settings › Modules you can add commands and scripts to queue, name commands that always run directly, or turn this off. KEHIKOT_DIRECT=1 in front of a command runs it directly.
