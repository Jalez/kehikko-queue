- **Shorter notices when a run finishes.** The line a session is told when its run ends now names only the project's folder, not its whole path, and ends with how to read the output.
- **Queue opens where you left it.** Its list keeps its scroll position on each kehikko and is back there the next time you come to it.
- **No more blank or half-drawn Queue while it starts.** Kehikot keeps its own cover up until Queue has drawn the queue, also for a Queue on a kehikko you are not looking at, and a Queue page that fails to draw now says why instead of staying empty.

## For agents
- The notice a session is told when its run finishes is shorter: it names the folder by its last part and ends with `queue_wait <id>`, the call that reads the run's output.
