- **Heavy work is no longer run outside the queue while Kehikot restarts.** A test suite or build an agent's guard sends to Queue now waits up to 20 seconds for Queue to come back, and is queued there, instead of running at once beside everything else. Only if Queue stays away does it run directly, and it says so.
- **Queue is found wherever it starts.** The command line looks for Queue where it is registered now, and through Kehikot's own address for it, every time, so a Queue that came back on another port is still found — also by a run that was being waited on when Kehikot restarted.

## For agents
- If the `queue_*` tools are missing after Kehikot restarted, run heavy work with Queue's CLI from the shell (`kehikot-queue run -- <command>` in the background, `kehikot-queue wait <id>` for a run already queued); the `/queue` skill does this for you.
