Kind: fix

- **The Queue stopped re-sending its whole history every few seconds.** Its page used to read the full list of runs, hundreds of kilobytes, each time the machine's load moved, which was about every five seconds. It now reads only what changed since it last looked: nothing new is a few bytes, a new run arrives alone. It still listens only while it is on screen.
- **A run whose process vanished no longer holds its slot.** If a command's process ended without reporting (killed outright, or gone while the Queue was away), the run is now marked "Lost", says its process ended without reporting, and the next waiting run starts. Before, it could stay listed as running indefinitely.

## For agents

- A run can now end as `lost` in `queue_status`, `queue_wait` and the CLI (exit 1): its process ended without reporting. Ask for it again if you still need the result.
