- **Agents are no longer stuck while their run waits in line.** When an agent's test suite or build is queued for it, an agent whose shell cannot wait in the background now gets its place in line back at once and carries on; it is told in its session when the run finishes.
- **Runs queued from a shell reach the session that asked.** A run queued from a shell with a place now records which project and epic it came from, and its result is told to that session.

## For agents
- `kehikot-queue run --detach` (or `KEHIKOT_DETACH=1`) queues a run and returns at once with its id; you are told in this session when it finishes. Read its output with `queue_wait` or `queue_status` and the id.
