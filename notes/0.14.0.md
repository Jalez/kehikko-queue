- **Limits by kind.** Each kind of heavy work has its own limit on how many run at once on this computer, from every session: one end-to-end run, one typecheck, two test suites, one build and two other tasks to begin with. Change them in Settings › Modules.
- **Who asked, and where it is in line.** Each waiting run shows the agent session that asked for it and its place in line, on the page, in the footer and to agents.
- **Dev servers in leased slots.** An agent can run a dev server in one of a few slots on a free port. Queue stops it when the agent is done with it, when its time runs out or when the agent's session ends, and you can stop one yourself on the page.
- **A safe stand-in for heavy commands.** `kehikot-queue run` labels a run from its command, stops a waiting run when the command that asked is closed or killed, and runs at once when it is already inside a queued run, so nothing waits behind itself.
