- **Test runs is now Queue.** It takes any heavy work every session on this computer asks for — test suites, builds, big installs and other resource-intensive commands — and starts it when there is room.
- **Builds and other tasks have their own kind.** A run can be tests (still the default), a build, or a task. Each run's kind shows on its row and in the results chart's tooltip.
- **Words that fit the run.** A failed test run still says "Tests failed" in the Inbox; a failed build or task says "Failed" with its name, and the page no longer calls everything a test run.
- **Agents queue more than tests.** Agent sessions are told to put builds and other heavy commands through the queue too, not only test suites.
