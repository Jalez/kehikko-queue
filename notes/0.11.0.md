- **Agents wait as long as a run takes.** An agent is given a command that waits on its run until it ends and exits with the run's result, to run in the background so it is woken when the run is done. Its wait also tells the agent how the run stands while it waits.
- **The session that asked hears the result.** When a run ends and nobody is waiting on it, Kehikot tells the agent session that asked for it, in one line, so it can pick up without you nudging it.
- **A folder that is not ready is said at once.** An untrusted mise config refuses a run straight away, a stale or missing node_modules is pointed out when the run is asked for, and an agent can add its own quick check that runs first.
- **Fast failures say what to fix.** A run that fails within seconds because of its folder (an untrusted mise config, a missing module or program) says so in its result.
