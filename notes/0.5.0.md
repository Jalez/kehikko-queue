- **A failed run says which one it is.** In the Inbox, a failure names the run, the branch or folder it ran in and who started it, and it is filed under the epic it was asked from.
- **Opening a failure takes you to it.** Opening a failed run from the Inbox shows that run in Test runs, highlighted and with its output open.
- **Seen failures stop asking.** Once you have seen a failure, from the Inbox or by opening its output, it leaves the Inbox's "needs you" and stays in the list of runs.
- **The runs that still need you stand out.** Each failure you have not seen yet has an outlined border and says "Needs your attention".
